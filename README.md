## 🎛 Current Project: Algorithm Visualizer
- Фреймворк для визуализации шагов выполнения алгоритмов  
- Базовый абстрактный класс `Algorithm`  
- Наследники: сортировки, поиск, графы, деревья  
- Планируется анимация: шаги, выделения, подсветка, статистика  
- Язык: Java (GUI на JavaFX / Swing)

## 📌 Roadmap
- Определить архитектуру: `Algorithm` + наследники  
- Реализация: `BubbleSort`, `InsertionSort`, `MergeSort`
- Визуализация сравнения элементов и их перестановок 
- Добавить поиск: `LinearSearch`, `BinarySearch`
- Добавить графы: `BFS`, `DFS`
